# C++ Core Library
This repository documents my journey of building a reusable C++ core library from scratch.

Instead of relying on the Standard Template Library (STL), I am implementing fundamental data structures and utility classes myself to gain a deep understanding of memory management, object-oriented programming, templates, operator overloading, file handling, and modern C++ design.

Each component is designed to be reusable in future projects such as banking systems, management systems, games, and other software engineering applications.
